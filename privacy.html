Runloop으로 돌아가기

Runloop 개인정보처리방침

시행일: 2026년 6월 21일

Runloop은 러닝 코스 추천, 코스 저장, 러닝 기록 관리를 제공하는 앱입니다. 본 방침은 Runloop이 처리하는 개인정보와 위치 정보의 이용 목적, 보관 방식, 제3자 서비스 이용 내역을 설명합니다.

1. 처리하는 정보

  • 위치 정보: 현재 위치 표시, 주변 러닝 코스 생성, 경로 보정, 러닝 거리 계산을 위해 사용합니다.
  • 앱 사용자가 입력하거나 저장한 정보: 닉네임, 주간 목표, 저장 코스, 러닝 기록, 메모 등 앱 이용 중 저장한 정보입니다.
  • AI 코스 추천 요청 정보: 현재 위치 좌표, 장소명, 목표 거리, 날씨 요약, 선호 조건, 저장 코스 이름 일부가 추천 생성을 위해 전송될 수 있습니다.
  • 검색 및 지도 이용 정보: 주소 검색, 장소 검색, 경로 보정 과정에서 검색어와 좌표가 지도/경로 API로 전송될 수 있습니다.

2. 이용 목적

  • 현재 위치 기반 지도 표시
  • 러닝 코스 추천 및 보행자 경로 보정
  • 저장 코스와 러닝 기록 관리
  • 앱 오류 확인 및 서비스 품질 개선

3. 위치 정보 처리

Runloop은 사용자가 위치 권한을 허용한 경우에만 위치 정보를 사용합니다. 현재 버전은 백그라운드 위치 추적을 목적으로 하지 않으며, 러닝 기록 화면 또는 코스 생성 화면처럼 사용자가 앱을 사용하는 동안 필요한 범위에서 위치를 처리합니다.

4. 보관 및 삭제

저장 코스, 러닝 기록, 프로필 설정 등은 기본적으로 사용자의 기기 브라우저 저장소 또는 앱 내부 저장소에 보관됩니다. 사용자는 앱 내 삭제 기능, 브라우저 데이터 삭제, 앱 삭제를 통해 해당 정보를 삭제할 수 있습니다.

5. 제3자 서비스

Runloop은 기능 제공을 위해 다음 외부 서비스를 사용할 수 있습니다.

  • Kakao Maps: 지도 표시, 주소 검색, 장소 검색
  • TMAP API: 보행자 경로 보정, 경로 거리 및 횡단보도 관련 정보 계산
  • OpenAI API: AI 러닝 코스 추천 생성
  • OpenWeather API: 날씨 정보 표시
  • Vercel: Runloop 웹앱 및 서버 API 호스팅

각 서비스는 기능 제공에 필요한 범위에서 요청 정보와 기술 정보를 처리할 수 있으며, 각 사업자의 개인정보처리방침이 적용될 수 있습니다.

6. 제3자 판매

Runloop은 사용자의 개인정보를 판매하지 않습니다.

7. 아동의 개인정보

Runloop은 만 14세 미만 아동을 주요 대상으로 하지 않습니다. 관련 법령상 보호자 동의가 필요한 정보가 확인될 경우 필요한 조치를 취합니다.

8. 문의

개인정보 관련 문의는 Google Play 스토어 등록 페이지에 표시되는 개발자 연락처 또는 Runloop 운영자에게 문의해 주세요.

9. 방침 변경

본 개인정보처리방침은 서비스 변경, 법령 변경, 외부 API 사용 변경에 따라 업데이트될 수 있습니다. 변경 시 본 페이지의 시행일을 갱신합니다.
